## [SolidJS](https://www.solidjs.com/) :-1:

* https://docs.solidjs.com/

| 维度         | SolidJS            | Vue 3                  | React                |
| ------------ | ------------------ | ---------------------- | -------------------- |
| UI 语法      | JSX                | Template / JSX         | JSX                  |
| 核心响应式   | Signal 依赖追踪    | Ref、Reactive 依赖追踪 | State 触发重新渲染   |
| 组件状态更新 | 组件通常不重执行   | 组件渲染函数更新       | 组件函数重新执行     |
| Virtual DOM  | 默认不用           | 默认使用               | 使用                 |
| DOM 更新粒度 | 绑定到具体动态节点 | 组件级更新 + 编译优化  | 重新渲染组件树后协调 |
| 计算属性     | `createMemo`       | `computed`             | `useMemo`            |
| 副作用       | `createEffect`     | `watchEffect`          | `useEffect`          |
| 单值状态     | `createSignal`     | `ref`                  | `useState`           |
| 对象状态     | `createStore`      | `reactive`             | 不可变对象 state     |
| 生命周期心智 | 响应式作用域       | 组件生命周期           | Render / Commit      |
| 生态规模     | 较小               | 大                     | 最大                 |
| 学习感受     | JSX + 响应式       | 模板 + 响应式          | 函数组件 + 快照模型  |
