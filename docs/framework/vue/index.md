## 面试常考的几个关键版本

### Vue 1.0（Evangelion）

* 第一版稳定发布
* 确立 MVVM 思想
* 双向绑定

### Vue 2.0（Ghost in the Shell）

* Virtual DOM 引入
* 性能大幅提升
* 成为主流版本

### Vue 2.6（Macross）

* 引入 Slot 新语法
* Vue CLI 3 时代
* Vue 2 最成熟版本

### Vue 2.7（Naruto）

* 被称为 "**Vue 2 的毕业版本**"
* 向 Vue 3 回移植：
    * Composition API
    * `<script setup>`
    * CSS v-bind

### Vue 3.0（One Piece）

* 最大版本升级
* Proxy 替代 Object.defineProperty
* Composition API
* Tree Shaking
* Fragment
* Teleport
* Suspense

### Vue 3.3（浪客剑心）

* TypeScript 支持大幅增强
* defineModel 实验特性

### Vue 3.4（灌篮高手）

* 新版响应式优化
* 性能进一步提升

### Vue 3.5（天元突破）

* Reactive Props Destructure
* useTemplateRef
* SSR 与 Hydration 优化
* Watcher 清理能力增强
