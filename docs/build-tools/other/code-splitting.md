# 代码分割（Code Splitting）

## 代码分割的作用是什么？

| 作用 | 说明 | 示例 |
|---|---|---|
| 按需加载 | 访问某项功能时才下载对应代码，减少首次加载量 | 进入管理页面时才加载图表库 |
| 分离公共代码 | 提取多个入口或页面共同使用的模块，减少重复 | 多个页面共享工具函数 |
| 改善缓存利用 | 更新业务代码时，未变化的公共代码可以继续使用缓存 | 将较稳定的依赖与业务代码分开 |

```js
// 用户打开图表时，再加载相关代码
async function showChart() {
  const { renderChart } = await import('./chart.js');
  renderChart();
}
```

需要区分：
- 代码分割：构建时拆出不同文件。
- 懒加载：运行时延迟加载这些文件。

代码分割是实现懒加载的基础，但拆出的文件也可以立即加载或提前预加载。分得过细还可能增加请求与调度开销。
