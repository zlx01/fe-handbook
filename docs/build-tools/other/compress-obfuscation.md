# 如何实现代码 / 资源压缩混淆

| 类型 | 实现方式 | 示例 |
|---|---|---|
| JS 压缩 | 删除注释与空白、简化表达式、缩短局部变量名、移除可证明无效的代码 | Terser、esbuild |
| CSS 压缩 | 删除空白与注释、简化颜色与数值、在安全条件下合并规则 | cssnano、Lightning CSS |
| HTML 压缩 | 删除注释、压缩可安全合并的空白等 | HTML 压缩工具 |
| 图片优化 | 调整尺寸、压缩质量、转换格式、删除元数据 | Sharp、图片编码器 |
| SVG 优化 | 删除冗余信息、简化路径与属性 | SVGO |
| 专门的代码混淆 | 字符串编码、控制流变换、插入干扰代码 | 专用混淆器 |
