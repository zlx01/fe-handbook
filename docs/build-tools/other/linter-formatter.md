# 代码规范和风格校验

## 代码规范和风格校验有哪些具体要求

| 类别 | 具体要求示例 | 常见工具 |
|---|---|---|
| 代码质量检查 | 禁止未使用变量、重复声明、不可达代码；检查 Hooks 使用规则、未处理的 Promise | ESLint |
| 格式统一 | 缩进、引号、分号、换行、行宽、尾逗号 | Prettier |
| 类型检查 | 参数与返回值类型匹配、空值处理、属性访问是否合法 | TypeScript、vue-tsc |

还可以根据团队需要增加：
- CSS 规则检查：重复声明、非法属性、选择器约束，通常使用 Stylelint。
- 依赖与架构约束：禁止跨层引用、禁止引入特定模块、约束循环依赖。
- 可访问性检查：图片替代文本、交互元素语义等，通过对应规则或专用工具完成。
