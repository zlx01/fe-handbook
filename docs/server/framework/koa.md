# [Koa](https://github.com/koajs/koa)



## Koa 和 Express 的区别

| 对比项     | Koa              | Express                        |
| ---------- | ---------------- | ------------------------------ |
| 定位       | 精简的中间件框架 | 功能相对完整的 Web 框架        |
| 异步模型   | async/await      | 支持 async，但历史上以回调为主 |
| 中间件模型 | 洋葱模型         | 主要是线性执行                 |
| 路由       | 不内置           | 内置                           |
| Body 解析  | 不内置           | 内置部分解析能力               |
| 核心体积   | 很小             | 相对更完整                     |
| 灵活性     | 高               | 开箱即用程度更高               |
| 配置成本   | 较高             | 较低                           |
