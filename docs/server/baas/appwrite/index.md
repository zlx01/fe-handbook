# [Appwrite](https://appwrite.io/)

Appwrite 是一个开源的应用开发平台，提供 BaaS（Backend as a Service，后端即服务）能力，整合身份认证、数据库、文件存储、服务端函数和实时通信等服务，帮助开发者构建 Web 和移动应用，支持使用 Appwrite Cloud 或自行部署。

- [官方文档](https://appwrite.io/docs)

## 核心能力

- **Auth**：提供用户注册、登录和身份管理，支持邮箱密码、OAuth 及多因素认证等方式。
- **Databases**：存储和查询应用数据，并通过权限配置控制数据访问。
- **Storage**：存储和管理图片、视频、文档等文件，支持文件访问权限控制。
- **Functions**：运行自定义服务端逻辑，响应 HTTP 请求、平台事件或定时任务。
- **Realtime**：订阅身份认证、数据库、文件存储等服务的事件，将变化实时推送到客户端。
- **Messaging**：通过电子邮件、短信和推送通知触达用户。
- **Sites**：部署和托管网站及 Web 应用，支持静态站点和服务端渲染应用。
