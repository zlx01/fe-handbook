# [Firebase](https://firebase.google.com/)

Firebase 是 Google 提供的应用开发平台，面向 Web、Android、Apple 平台及 Flutter 等应用，提供 BaaS（Backend as a Service，后端即服务）能力，并整合应用托管、质量监控和数据分析服务，帮助开发者构建和运营应用。

- [官方文档](https://firebase.google.com/docs)

## 核心能力

- **Cloud Firestore / Realtime Database**：提供云端数据库，用于应用数据存储和实时同步。
- **Authentication**：提供用户身份认证，支持邮箱密码、手机号及第三方身份提供商等登录方式。
- **Cloud Storage**：存储和管理图片、视频等用户上传的文件。
- **Cloud Functions**：运行服务端逻辑，响应应用事件或 HTTP 请求。
- **Hosting / App Hosting**：提供网站和 Web 应用托管能力。
- **Cloud Messaging**：向客户端发送通知和数据消息。
- **Crashlytics / Performance Monitoring / Google Analytics**：帮助跟踪崩溃、监测性能和分析应用使用情况。
