# [Google Analytics](https://analytics.google.com/analytics/web/provision/#/provision)

## UTM Parameters

| 参数           | 含义                  | 示例                             |
| -------------- | --------------------- | -------------------------------- |
| `utm_source`   | **来源是谁**          | `google`、`wechat`、`newsletter` |
| `utm_medium`   | **通过什么渠道/媒介** | `cpc`、`email`、`social`         |
| `utm_campaign` | **属于哪个营销活动**  | `618`、`summer_sale`             |
| `utm_content`  | 区分具体广告/素材     | `banner_a`                       |
| `utm_term`     | 搜索关键词等          | `iphone`                         |
