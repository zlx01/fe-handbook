# [UnoCSS](https://unocss.dev/)

| 维度       | Tailwind CSS               | UnoCSS                                          |
| ---------- | -------------------------- | ----------------------------------------------- |
| 定位       | Utility-first CSS 框架     | 按需原子 CSS 引擎                               |
| 默认规则   | 完整、统一、官方定义       | 本身几乎无规则，通过 Preset 注入                |
| 使用方式   | 主要使用 Tailwind 官方语法 | 可以模拟 Tailwind，也可以自定义一套语法         |
| 配置理念   | 约定优先                   | 高度可编程                                      |
| 生态规模   | 更大，组件库和模板更多     | 相对较小，偏工程工具生态                        |
| 特殊能力   | 标准 Utility Class 工作流  | Attributify、Shortcuts、自定义 Rules、Preset 等 |
| 团队一致性 | 较强                       | 自由度高，但更容易产生私有规范                  |
| 适合场景   | 常规业务、跨团队项目       | 定制设计系统、Vue/Vite 项目、工具链爱好者       |
