伪元素 ​

允许你对被选择元素的特定部分修改样式

  • ::before
  • ::after

::before ::after ​

由 ::before 和 ::after 伪元素生成的盒子，就好像它们是应用它们的元素或“原始元素（originating element）”的直接子元素一样，因此不能应用在替换元素上，比如 元素，其内容不在 CSS 格式化模型的范围内。

可替换元素：https://developer.mozilla.org/en-US/docs/Web/CSS/Replaced_element
