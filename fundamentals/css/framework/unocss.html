UnoCSS ​

维度Tailwind CSSUnoCSS
定位Utility-first CSS 框架按需原子 CSS 引擎
默认规则完整、统一、官方定义本身几乎无规则，通过 Preset 注入
使用方式主要使用 Tailwind 官方语法可以模拟 Tailwind，也可以自定义一套语法
配置理念约定优先高度可编程
生态规模更大，组件库和模板更多相对较小，偏工程工具生态
特殊能力标准 Utility Class 工作流Attributify、Shortcuts、自定义 Rules、Preset 等
团队一致性较强自由度高，但更容易产生私有规范
适合场景常规业务、跨团队项目定制设计系统、Vue/Vite 项目、工具链爱好者
